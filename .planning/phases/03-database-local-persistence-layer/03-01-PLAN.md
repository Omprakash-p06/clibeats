## Task 2: Wire Dependencies into app/build.gradle.kts

<read_first>
- `app/build.gradle.kts` — current dependencies block
- `gradle/libs.versions.toml` — verify lib refs added in Task 1
</read_first>

<action>
Open `app/build.gradle.kts`. In the `dependencies { }` block, add:

```kotlin
implementation(libs.room.runtime)
implementation(libs.room.ktx)
ksp(libs.room.compiler)
implementation(libs.datastore.preferences)
testImplementation(libs.room.testing)
testImplementation(libs.coroutines.test)
androidTestImplementation(libs.room.testing)
androidTestImplementation(libs.coroutines.test)
```

Also add the `room.schemaLocation` KSP argument to the `ksp { }` block (create it if it does not exist):

```kotlin
ksp {
    arg("room.schemaLocation", "$projectDir/schemas")
}
```

This tells the KSP Room processor where to export the JSON schema files that enable verified migrations.
</action>

<acceptance_criteria>
- `app/build.gradle.kts` contains `implementation(libs.room.runtime)`
- `app/build.gradle.kts` contains `ksp(libs.room.compiler)`
- `app/build.gradle.kts` contains `implementation(libs.datastore.preferences)`
- `app/build.gradle.kts` contains `testImplementation(libs.room.testing)`
- `app/build.gradle.kts` contains `testImplementation(libs.coroutines.test)`
- `app/build.gradle.kts` contains `arg("room.schemaLocation"`
- `./gradlew assembleDebug` exits 0 with `BUILD SUCCESSFUL`
</acceptance_criteria>
