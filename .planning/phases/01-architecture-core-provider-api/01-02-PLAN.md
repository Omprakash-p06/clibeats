<objective>
Define all core domain models (Track, Album, Artist, Playlist, PlaybackState) and the MusicProvider abstraction interface with a sealed ProviderResult type.

Purpose: These contracts are the central language of CLIBeats — every other layer (Data adapters, ViewModels, UI) speaks through these types. Defining them first with no Android dependencies makes the domain layer portable and independently testable.

Output:
- 5 immutable domain model data classes under `domain/model/`
- `MusicProvider` interface under `domain/provider/` with 5 suspend functions
- `ProviderResult<T>` sealed class (Success, Error, Loading) for type-safe provider responses

## Design Decisions
- All domain models are `data class` for structural equality, copy(), and destructuring
- Nullable fields used only for genuinely optional data (e.g., `artworkUrl` may be null for tracks without artwork)
- `MusicProvider` is an `interface` (not abstract class) so multiple providers can co-exist via Hilt multi-bindings in a later phase
- `ProviderResult` is a sealed class (not kotlin.Result) so UI can explicitly handle Loading state

Domain model contracts (define these exactly):
```kotlin
// Track.kt
data class Track(
    val id: String,
    val title: String,
    val artist: String,
    val album: String,
    val durationMs: Long,
    val artworkUrl: String?,
    val streamUrl: String?,
    val providerId: String        // which provider owns this track
)

// PlaybackState.kt
data class PlaybackState(
    val currentTrack: Track?,
    val isPlaying: Boolean,
    val positionMs: Long,
    val bufferedPositionMs: Long,
    val repeatMode: RepeatMode,
    val shuffleEnabled: Boolean
)

enum class RepeatMode { OFF, ONE, ALL }

// ProviderResult.kt
sealed class ProviderResult<out T> {
    data class Success<T>(val data: T) : ProviderResult<T>()
    data class Error(val message: String, val cause: Throwable? = null) : ProviderResult<Nothing>()
    object Loading : ProviderResult<Nothing>()
}

// MusicProvider.kt
interface MusicProvider {
    val providerId: String
    val displayName: String
    suspend fun search(query: String, limit: Int = 20): ProviderResult<List<Track>>
    suspend fun getTrack(trackId: String): ProviderResult<Track>
    suspend fun stream(trackId: String): ProviderResult<String>    // returns stream URL
    suspend fun playlists(): ProviderResult<List<Playlist>>
    suspend fun queue(): ProviderResult<List<Track>>
}
```
