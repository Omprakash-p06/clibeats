# Plan 10-01: Structured Telemetry & Crash Reporting Abstraction

## Objective
Implement a privacy-first telemetry tracking and crash reporting abstraction layer that logs structured events while preventing PII / authentication token leakage.

## must_haves
- `AnalyticsEvent` sealed class defining structured events
- `TelemetryTracker` interface & `TimberTelemetryTracker` implementation
- `CrashReporter` interface & `TimberCrashReporter` implementation with automated PII scrubbing
- `TelemetryModule` providing Hilt bindings

## Tasks

### Task 1: Create Telemetry Core Abstractions

<action>
Create `app/src/main/java/com/clibeats/telemetry/AnalyticsEvent.kt`:
```kotlin
package com.clibeats.telemetry

sealed class AnalyticsEvent(val name: String, val params: Map<String, String> = emptyMap()) {
    data class PlaybackStarted(val trackId: String, val providerId: String) :
        AnalyticsEvent("playback_started", mapOf("track_id" to trackId, "provider_id" to providerId))

    data class PlaybackPaused(val trackId: String) :
        AnalyticsEvent("playback_paused", mapOf("track_id" to trackId))

    data class SearchExecuted(val providerId: String) :
        AnalyticsEvent("search_executed", mapOf("provider_id" to providerId))

    data class CacheCleared(val freedBytes: Long) :
        AnalyticsEvent("cache_cleared", mapOf("freed_bytes" to freedBytes.toString()))
}
```

Create `app/src/main/java/com/clibeats/telemetry/TelemetryTracker.kt`:
```kotlin
package com.clibeats.telemetry

interface TelemetryTracker {
    fun trackEvent(event: AnalyticsEvent)
}
```

Create `app/src/main/java/com/clibeats/telemetry/CrashReporter.kt`:
```kotlin

interface CrashReporter {
    fun logException(throwable: Throwable, message: String? = null)
}
```
</action>

### Task 2: Create Timber Implementations & Hilt Module

<action>
Create `app/src/main/java/com/clibeats/telemetry/TimberTelemetryTracker.kt`:
```kotlin
package com.clibeats.telemetry

import timber.log.Timber
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class TimberTelemetryTracker @Inject constructor() : TelemetryTracker {
    override fun trackEvent(event: AnalyticsEvent) {
        Timber.d("TELEMETRY: event=%s params=%s", event.name, event.params)
    }
}
```

Create `app/src/main/java/com/clibeats/telemetry/TimberCrashReporter.kt`:
```kotlin
package com.clibeats.telemetry

import timber.log.Timber
import javax.inject.Inject
import javax.inject.Singleton

@Singleton
class TimberCrashReporter @Inject constructor() : CrashReporter {
    override fun logException(throwable: Throwable, message: String?) {
        val sanitizedMsg = message?.replace(Regex("Bearer\\s+[A-Za-z0-9._-]+"), "Bearer [REDACTED]")
        Timber.e(throwable, "CRASH_REPORT: %s", sanitizedMsg ?: throwable.localizedMessage)
    }
}
```

Create `app/src/main/java/com/clibeats/di/TelemetryModule.kt`:
```kotlin
package com.clibeats.di

import com.clibeats.telemetry.CrashReporter
import com.clibeats.telemetry.TelemetryTracker
import com.clibeats.telemetry.TimberCrashReporter
import com.clibeats.telemetry.TimberTelemetryTracker
import dagger.Binds
import dagger.Module
import dagger.hilt.InstallIn
import dagger.hilt.components.SingletonComponent
import javax.inject.Singleton

@Module
@InstallIn(SingletonComponent::class)
abstract class TelemetryModule {

    @Binds
    @Singleton
    abstract fun bindTelemetryTracker(impl: TimberTelemetryTracker): TelemetryTracker

    @Binds
    @Singleton
    abstract fun bindCrashReporter(impl: TimberCrashReporter): CrashReporter
}
```
</action>
