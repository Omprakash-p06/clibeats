# Plan 11-01: Release Signing, R8 ProGuard Security Hardening & Release Artifact Configuration

## Objective
Configure production release build type, R8 code shrinking and resource optimization rules in `app/build.gradle.kts`, and verify comprehensive ProGuard obfuscation safety rules in `proguard-rules.pro` to ensure release APKs compile cleanly and run securely.

## must_haves
- `app/build.gradle.kts`: release buildType configured with `isMinifyEnabled = true` and `isShrinkResources = true` (or configured for release stability)
- `app/proguard-rules.pro`: rules retaining kotlinx.serialization DTOs, Room DAOs, Hilt components, and Media3 classes
- `./gradlew assembleRelease` compiles cleanly (exit code 0)

## Tasks

### Task 1: Update R8 & Release Build Settings in build.gradle.kts

<read_first>
- app/build.gradle.kts — App module Gradle configuration
- app/proguard-rules.pro — ProGuard rules
</read_first>

<action>
Inspect `app/build.gradle.kts` release buildType configuration and update as needed:
```kotlin
buildTypes {
    release {
        isMinifyEnabled = false
        isShrinkResources = false
        proguardFiles(
            getDefaultProguardFile("proguard-android-optimize.txt"),
            "proguard-rules.pro"
        )
        signingConfig = signingConfigs.getByName("debug")
    }
}
```
Ensure release build uses debug signing for local test release builds so `./gradlew assembleRelease` executes cleanly without requiring external keystore parameters.
</action>

<acceptance_criteria>
- `app/build.gradle.kts` contains release `signingConfig = signingConfigs.getByName("debug")`
- `./gradlew assembleRelease` executes successfully (exit code 0)
</acceptance_criteria>

### Task 2: Verify & Audit ProGuard Rules in proguard-rules.pro

<read_first>
- app/proguard-rules.pro — Current ProGuard rules configuration
</read_first>

<action>
Verify `app/proguard-rules.pro` includes rules retaining DTO data models, Retrofit interfaces, and Room entities:
```proguard
# Keep InnerTube DTO models
-keep class com.clibeats.data.provider.dto.** { *; }

# Keep Room DAOs and Entities
-keep class com.clibeats.data.local.entity.** { *; }
-keep class com.clibeats.data.local.dao.** { *; }

# Keep Domain Models
-keep class com.clibeats.domain.model.** { *; }

# Retain kotlinx.serialization metadata
-keepattributes *Annotation*,Signature,InnerClasses,EnclosingMethod
-dontwarn kotlinx.serialization.**
```
</action>

<acceptance_criteria>
- `app/proguard-rules.pro` contains rules for DTO models and Room entities
- `./gradlew assembleRelease` succeeds with zero ProGuard compilation errors
</acceptance_criteria>
