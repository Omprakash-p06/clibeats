# Plan 03-05: Phase 3 Gap Closure — Encrypted Storage, Mapper Integrity, Foreign Keys & Query Safety

## Objective
Close all diagnosed gaps from Phase 3 verification (`03-VERIFICATION.md`):
1. **Encrypted Storage (REQ-OFF-03 / REQ-ENG-09)**: Implement Android Keystore-backed `EncryptedSharedPreferences` for sensitive credentials (`AUTH_TOKEN`), exclude secret files from cloud backup via `data_extraction_rules.xml`, and update `ADR-003` to reflect the actual Keystore security implementation.
2. **Mapper Integrity**: Update `SongMapper` and `PlaylistMapper` to preserve local caching fields (`localPath`, `cachedAt`) and `createdAt` timestamps so `REPLACE` upserts do not wipe data.
3. **Foreign Key Cascades**: Add Room `@ForeignKey` constraints with `CASCADE` deletion on `PlaylistSongCrossRef` to prevent orphaned cross-ref rows.
4. **LIKE Query Safety**: Escape `%` and `_` wildcards in `SongDao.searchAsFlow` to prevent wildcard injection search broadening.

## Task 3: Add Foreign Keys with Cascade Delete to PlaylistSongCrossRef

<read_first>
- `app/src/main/java/com/clibeats/data/local/entity/PlaylistSongCrossRef.kt`
- `app/src/main/java/com/clibeats/data/local/entity/PlaylistEntity.kt`

</read_first>

<action>
Update `app/src/main/java/com/clibeats/data/local/entity/PlaylistSongCrossRef.kt` to define `@ForeignKey` constraints for `PlaylistEntity` and `SongEntity` with `onDelete = ForeignKey.CASCADE`:

```kotlin
package com.clibeats.data.local.entity

import androidx.room.ColumnInfo
import androidx.room.Entity
import androidx.room.ForeignKey
import androidx.room.Index

@Entity(
    tableName = "playlist_song_cross_ref",
    primaryKeys = ["playlist_id", "song_id"],
    foreignKeys = [
        ForeignKey(
            entity = PlaylistEntity::class,
            parentColumns = ["id"],
            childColumns = ["playlist_id"],
            onDelete = ForeignKey.CASCADE,
        ),
        ForeignKey(
            entity = SongEntity::class,
            parentColumns = ["id"],
            childColumns = ["song_id"],
            onDelete = ForeignKey.CASCADE,
        ),
    ],
    indices = [
        Index("playlist_id"),
        Index("song_id"),
    ],
)
data class PlaylistSongCrossRef(
    @ColumnInfo(name = "playlist_id") val playlistId: String,
    @ColumnInfo(name = "song_id") val songId: String,
    @ColumnInfo(name = "position") val position: Int,
)
```
</action>

<acceptance_criteria>
- `PlaylistSongCrossRef.kt` contains `onDelete = ForeignKey.CASCADE` for both `PlaylistEntity` and `SongEntity`
- `PlaylistSongCrossRef.kt` includes indices on `playlist_id` and `song_id`
- Schema export `1.json` is updated and clean compile passes
</acceptance_criteria>
