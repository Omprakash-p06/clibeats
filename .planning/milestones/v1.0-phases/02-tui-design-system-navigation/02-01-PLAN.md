## Objective

Implement the complete Material3 `CliBeatsTheme` — color scheme, JetBrains Mono typography, and shape tokens — as a self-contained theme module that every other Phase 2 component depends on.

```kotlin
package com.clibeats.presentation.theme

import androidx.compose.material3.MaterialTheme
import androidx.compose.runtime.Composable

/**
 * CLIBeats Material3 theme.
 *
 * Always dark — does not respond to system light/dark mode setting.
 * Dynamic color disabled — brand palette is fixed per UI-SPEC.
 */
@Composable
fun CliBeatsTheme(
    content: @Composable () -> Unit,
) {
    MaterialTheme(
        colorScheme = CliBeatsColorScheme,
        typography  = CliBeatsTypography,
        shapes      = CliBeatsShapes,
        content     = content,
    )
}
```
