# Phase 2 — UI Design Contract: TUI Design System & Navigation Layout

> Visual and interaction contract for the CLIBeats monochrome TUI design system.
> Generated by gsd-ui-phase, verified by gsd-ui-checker.
> All values below are LOCKED. Planner and executor agents MUST NOT deviate from these values.

## Design System

| Property | Value |
|----------|-------|
| Tool | none (Android Compose Material 3 — no shadcn/web tooling) |
| Preset | TUI Monochrome — inspired by terminal UIs (tmux, btop, ncmpcpp) |

## Color System

### Primary Palette (60-30-10 rule)

| Role | Token Name | Hex Value | Usage |
|------|-----------|-----------|-------|
| Background (60%) | `CliBeatsBackground` | `#0D0D0D` | Root scaffold background, all screen backgrounds |
| Surface (30%) | `CliBeatsSurface` | `#151515` | Cards, nav drawer/rail, bottom player bar, dialogs |
| Surface Variant | `CliBeatsSurfaceVariant` | `#1E1E1E` | Hover states, selected row highlight, divider areas |
| Accent (10%) | `CliBeatsAccent` | `#1DB954` | Active nav item, now-playing indicator, play button, progress bar |
| Text Primary | `CliBeatsTextPrimary` | `#FFFFFF` | Track titles, primary labels, app bar title |
| Text Secondary | `CliBeatsTextSecondary` | `#A0A0A0` | Artist name, metadata, duration, timestamps |
| Text Disabled | `CliBeatsTextDisabled` | `#505050` | Placeholder text, disabled controls |
| Divider | `CliBeatsDivider` | `#2A2A2A` | Row separators, section dividers |
| Destructive | `CliBeatsDestructive` | `#E53935` | Delete actions, error states only |
| Destructive Surface | `CliBeatsDestructiveSurface` | `#3B1515` | Error snackbar background |

### Accent Usage Contract (STRICT)

Accent `#1DB954` is reserved **exclusively** for:
- Active / selected navigation item icon and label
- Now-playing row left border indicator (2dp vertical bar)
- Play / Pause button fill
- Audio progress bar and seek thumb
- Checkbox / toggle checked state

**Accent MUST NOT appear on:** general buttons, app bar, backgrounds, text links, loading indicators, or decorative elements.

### MaterialTheme Mapping

```kotlin
// Exact ColorScheme values for MaterialTheme.colorScheme
backgroundColor    = Color(0xFF0D0D0D)  // background
surfaceColor       = Color(0xFF151515)  // surface + surfaceContainer

primaryColor       = Color(0xFF1DB954)  // primary (accent)
onPrimaryColor     = Color(0xFF000000)  // onPrimary
onBackgroundColor  = Color(0xFFFFFFFF)  // onBackground
onSurfaceColor     = Color(0xFFFFFFFF)  // onSurface
onSurfaceVariant   = Color(0xFFA0A0A0)  // onSurfaceVariant
outlineColor       = Color(0xFF2A2A2A)  // outline (dividers)
errorColor         = Color(0xFFE53935)  // error
```

## Typography

Font family: **JetBrains Mono** (all roles — monospace is a core design requirement, not optional).
Fallback: `FontFamily.Monospace` (system monospace).

| Role | Token | Size | Weight | Line Height | Letter Spacing | Usage |
|------|-------|------|--------|-------------|----------------|-------|
| Title Large | `titleLarge` | 18sp | SemiBold (600) | 1.3 | 0sp | Screen headers, now-playing track name |
| Title Medium | `titleMedium` | 16sp | Medium (500) | 1.3 | 0sp | Section headings, album name |
| Body Large | `bodyLarge` | 14sp | Normal (400) | 1.4 | 0sp | Song table primary text (track title) |
| Body Medium | `bodyMedium` | 13sp | Normal (400) | 1.4 | 0sp | Navigation labels, secondary content |
| Label Large | `labelLarge` | 12sp | Medium (500) | 1.2 | 0.5sp | Metadata chips, badges, keyboard shortcuts |
| Label Medium | `labelMedium` | 11sp | Normal (400) | 1.2 | 0.5sp | Duration display, timestamp, counts |
| Label Small | `labelSmall` | 10sp | Normal (400) | 1.2 | 0.5sp | Status indicators, tooltips |

**Typography rules:**
- NO serif or sans-serif fonts anywhere — JetBrains Mono only.
- NO italic text in the TUI — purely aesthetic decision for terminal feel.
- Text must NEVER be centered in list rows — always start-aligned.
- Duration/time values use tabular figures (JetBrains Mono is inherently tabular).

## Spacing Scale (dp units)

All spacing values are multiples of 4dp.

| Token | dp | Usage |
|-------|-----|-------|
| `space2` | 2dp | Micro gaps (icon-to-text in dense rows) |
| `space4` | 4dp | `xs` — inline padding, icon gaps |
| `space8` | 8dp | `sm` — compact element spacing, row inner padding |
| `space12` | 12dp | Between metadata elements in song row |
| `space16` | 16dp | `md` — default horizontal padding, card padding |
| `space24` | 24dp | `lg` — section padding, nav item padding |
| `space32` | 32dp | `xl` — layout section gaps |
| `space48` | 48dp | `2xl` — component height (song row, app bar, player bar) |
| `space64` | 64dp | Nav rail width (collapsed) |

Exceptions: none — all spacing uses this scale.

## Motion & Animation

| Context | Duration | Easing | Notes |
|---------|----------|--------|-------|
| Screen transitions | 120ms | `FastOutSlowIn` | Slide 24dp horizontal |
| Nav item activation | 80ms | `LinearOutSlowIn` | Icon color crossfade only |
| Row hover | 100ms | Linear | Background color fade |
| Player bar expand | 150ms | `FastOutSlowIn` | Slide up from bottom |
| Search bar open | 120ms | `FastOutSlowIn` | Width expand from right |
| Snackbar | 100ms enter / 80ms exit | `FastOutSlowIn` | |

**Animation rules (STRICT):**
- NO bounce, overshoot, spring, or elastic curves — terminal UIs are linear/ease only.
- NO blur or glassmorphism.
- NO gradient backgrounds (solid colors only).
- NO loading spinners with scale animations — use linear progress bars.
- All transitions must complete in ≤150ms. Nothing longer.

## Accessibility Contract

| Requirement | Value |
|-------------|-------|
| Minimum touch target | 48×48dp for all interactive elements |
| Text contrast (primary) | `#FFFFFF` on `#0D0D0D` → **21:1** (exceeds WCAG AAA) |
| Text contrast (secondary) | `#A0A0A0` on `#0D0D0D` → **5.74:1** (WCAG AA) |
| Accent on surface | `#1DB954` on `#151515` → **7.5:1** (WCAG AAA) |
| Content descriptions | Every icon-only button MUST have `contentDescription` |
| Nav rail items | `semantics { role = Role.Tab }` |
| Song rows | `semantics { contentDescription = "$trackTitle by $artist" }` |
| Player bar | Accessible play/pause: `contentDescription = "Pause $trackTitle"` |
| Focus traversal | Logical top-to-bottom, left-to-right — no focus traps |
| Screen reader | All player controls individually focusable with descriptive labels |

## Copywriting Contract

| Element | Copy |
|---------|------|
| App title | `CLIBeats` |
| Nav: Home | `Home` |
| Nav: Search | `Search` |
| Nav: Library | `Library` |
| Nav: Playlists | `Playlists` |
| Nav: Queue | `Queue` |
| Nav: Settings | `Settings` |
| Search placeholder | `Search tracks, artists, albums…` |
| Search empty state heading | `No results` |
| Search empty state body | `Try a different search term` |
| Library empty state heading | `Your library is empty` |
| Library empty state body | `Search for music to get started` |
| Queue empty state heading | `Queue is empty` |
| Queue empty state body | `Add tracks to start listening` |
| Error state | `Something went wrong. Check your connection.` |
| Delete playlist confirmation | `Delete playlist: This cannot be undone.` |
| Player: nothing playing | `Not playing` |
| Player: unknown artist | `Unknown artist` |

**Copywriting rules:**
- Sentence case only (NOT SHOUTING CAPS unless it's a section header like `MAIN`).
- No exclamation marks in UI copy.
- No emoji in UI copy.
- Error messages include a resolution path, never just "Error".
